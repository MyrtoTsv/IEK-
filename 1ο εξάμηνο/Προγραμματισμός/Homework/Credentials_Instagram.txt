Credentials : Login sto username kai password.
Diadikasia . Mpainei me ta stoxeia kai tou kanei verify an einai swsta h oxi

Na grafei programma se glwssa C to opoio na ulopoiei to login session sto Instagram.Pio sugkekrimena
tha uparxoun apothikeumena mesa ston kwdika to swsto username kai to swsto password enos xrhsth tou Instagram
(Parathrhsh:Otan leme apothikeumena , ennoume char username[STR_SIZE]='...' char password[STR_SIZE]='...')
H efarmogh sas tha dinei treis eukairies ston xrhsth (strcmp) na eisagei to swsto username kai password.
An to dwsei swsta , tha dei to munhma "Welcome to Instagram" (s1=s2)
An kanei lathos , tha dei to katallhlo munhma gia na ksanaprospathiseimono 3 fores (s1<s2 , s1>s2)
An kanei kai tis treis fores lathos , h efarmogh tha enhmerwnei ton xrhsth oti to account kleidwthike kai stalthike SMS ston pragmatiko dikaiouxo.

#include <stdio.h>
#include <string.h>

#define STR_SIZE 20 //Endeiktiko
#define MAX_PROSPATHIES 3 //Oi max prospathies thelome na einai 3

int main() {
	//Apothikeuoume to username kai pass se pinakes string.Auta einai ta swsta
    char username[STR_SIZE] = "myrtw";
    char password[STR_SIZE] = "pass123";
    
    //Apothikeoume ta input tou xrhsth se kainourious pinakes string gia na ta
    //sugkrinoume meta
    char inputUsername[STR_SIZE];
    char inputPassword[STR_SIZE];

    //Sthn arxh theloume oi prospatheies na einai 0.
    int prospathies = 0;
  
    //Oso oi einai < 3 , ektupwne mexri na vreis to swsto
    while (prospathies < MAX_PROSPATHIES) {
        printf("Enter username: ");
        scanf("%s", inputUsername);

        printf("Enter password: ");
        scanf("%s", inputPassword);

        //Vazoume strcmp sta kainouria strings arrays.An einai kai ta duo ==0
        //Vazoume duo strcmp me san input duo strings , giati strcmp(s1,s2)
        //Sugkrinei ta ASCII codes tous.An vgei 0, einai idianara Welcome to instagram
        if (strcmp(username, inputUsername) == 0 &&
            strcmp(password, inputPassword) == 0) {

            printf("\nWelcome to Instagram!\n");
            return 0;
            
        //An den vgei =0,ektypwse munhma lathous kai ksanaprospathise
        //O logos pou den tha einai 0 , tha dyo
        } else {
            printf("Lathos credentials.Ksanaprospathise.\n");
            
        
            //Eite s1<s2 kai se auth thn periptwsh ektupwse to
            if (strcmp(username, inputUsername) < 0)
                printf("O logos einai oti (s1 < s2)\n");
            //Eite s1>s2 kai se auth thn periptwsh ektypwse to
            else if (strcmp(username, inputUsername) > 0)
                printf("O logos einai oti (s1 > s2)\n");

            //Oso eisai mesa sto while , gia kathe lathos prospathia , aukshse tis prospathies kata 1
            prospathies++;
            //To MAX_PROSPATHIES - prospathies , einai gia na mas vgazei 3-1=2 prospathies apomenoun
            printf("Apomenoun: %d prospatheies\n\n", MAX_PROSPATHIES - prospathies);
        }
    }

    //Ektupwse auto to munhma, exontas apotuxei kai stis 3 prospathies 
    printf("O logariasmos kleidwthike\n");
    printf("Stalthike SMS ston pragmatiko dikaiouxo\n");
    printf("Exiting...");
    return 0;
}
